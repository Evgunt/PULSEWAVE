# PULSEWAVE 4.0 — Private Network Manager

**PULSEWAVE** — настольное приложение для Windows: импорт и диагностика proxy-профилей, оценка доступности серверов и управление локальным TUN-подключением через отдельный процесс sing-box.

> Проект является независимым программным инструментом. Он не предоставляет VPN-серверы, подписки или услуги связи. Пользователь самостоятельно выбирает конфигурации и отвечает за законность их получения, использования и распространения.

## Возможности

- Проверка VLESS / VMess / Trojan-профилей через sing-box.
- Параллельная проверка с настройкой количества одновременных задач.
- Таблица результатов, сортировка и экспорт CSV.
- Редактирование списка источников.
- TUN-подключение через sing-box для выбранного профиля (Windows, права администратора/UAC).
- Публикация fast_vless.txt в выбранный GitHub-репозиторий через GitHub Contents API.
- Автоматическая проверка по расписанию: 15, 30, 60, 120 или 240 минут.
- Системный трей, сворачивание при закрытии и быстрый запуск проверки.
- Автозапуск Windows для текущего пользователя.
- Журнал работы и сохранение локальных настроек.

## Требования

- Windows 10/11 x64.
- Python 3.11 x64 для запуска из исходников и сборки.
- Официальная Windows x64-сборка sing-box, которую пользователь скачивает самостоятельно и размещает в `singBox/sing-box.exe`.
- Для TUN: запуск с правами администратора через стандартный запрос UAC; совместимая версия sing-box и её необходимые runtime-компоненты.

Загрузите sing-box только из официального проекта: <https://github.com/SagerNet/sing-box/releases>.

PULSEWAVE не содержит бинарный файл sing-box ни в репозитории, ни в сборке приложения. Sing-box — отдельная программа со своей лицензией (GPL-3.0-or-later); пользователь скачивает её самостоятельно с официальной страницы релизов. Не заявляйте об официальной связи с SagerNet.

## Запуск из исходников

```powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
copy sources.example.txt sources.txt
python gui.py
```

После этого откройте `sources.txt` и добавьте свои разрешённые HTTPS-источники. Для проверки и TUN-подключения скачайте `sing-box.exe` с официальной страницы релизов и самостоятельно положите его в `singBox`.

## Сборка Windows EXE

1. Установите Python 3.11 x64 и добавьте Python Launcher (`py`) в PATH.
2. Скачайте официальный `sing-box.exe` для Windows x64 и поместите в `singBox`.
3. Запустите `build_exe.bat`.
4. Готовая папка будет в `dist\PULSEWAVE\`. Переносите всю папку, а не один EXE.

Сборка выполняется на Windows. В этой среде Linux готовый Windows EXE не собирается и не тестируется.

## TUN: ограничения и безопасность

- TUN меняет системную маршрутизацию Windows. Подключайте только доверенные конфигурации и серверы.
- Для TUN нужен повышенный уровень прав. Приложение запрашивает UAC; не отключайте UAC.
- Перед использованием проверьте совместимость версии sing-box и её конфигурационного формата.
- Приложение не обещает защиту от всех утечек трафика и не реализует полноценный kill switch. При критичных сценариях используйте отдельный проверенный механизм блокировки трафика и тестируйте DNS/IPv6/маршруты.
- Не используйте приложение для нарушения закона, доступа к данным без разрешения, атак, распространения вредоносного ПО или нарушения условий провайдера.

## Данные и приватность

По умолчанию проверочные результаты, источники, настройки и логи хранятся локально. При включении Git-публикации программа показывает предупреждение: файл результатов может содержать идентификаторы и реквизиты доступа. Перед публикацией проверьте содержимое вручную.

Приложение не является VPN-провайдером и не собирает централизованную телеметрию. HTTP-запросы к тестовым URL и источникам выполняются для проверки доступности и зависят от локальных настроек.

## GitHub: публикация списка для телефона

В настройках PULSEWAVE нажмите «Настроить GitHub…» и укажите владельца репозитория, имя репозитория и ветку. Создайте fine-grained Personal Access Token только для выбранного репозитория с разрешением **Contents: Read and write**. Токен сохраняется через Windows Credential Manager; в `vlesschecker_ui.json` он не записывается.

После включения «Публиковать fast_vless.txt в GitHub после проверки» PULSEWAVE обновляет файл `fast_vless.txt` через GitHub Contents API. Существующий файл обновляется по его SHA, новый файл создаётся автоматически. Репозиторий должен уже существовать, а выбранная ветка — быть создана.

**Внимание:** VLESS-ссылки могут содержать UUID, адреса серверов и другие секреты доступа. Публикуй их только в репозитории с подходящими настройками приватности и только если у тебя есть право делиться этими конфигурациями. Публичный репозиторий делает ссылки доступными всем.

## Автоматическая проверка

В блоке «Автоматическая проверка» включи расписание и выбери интервал. Отсчёт начинается после включения расписания; после каждой завершившейся плановой проверки следующий запуск планируется через выбранный интервал. Если предыдущая проверка ещё выполняется, параллельный запуск не создаётся. Приложение должно оставаться запущенным (можно свернуть его в системный трей).
